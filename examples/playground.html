mport examples / playground

Routing playground

mport decides which exact version of a package you get once, then lets which CDN serves it change when CDNs are slow, down or wrong. Pick a scenario: each one sets up the controls below, breaks something, and tells you what to look for. Registry lookups and CDN requests are real; outages, latency and tampered bytes are simulated with a fetch wrapper passed to createRouter({ fetch }).

Circuit breaker

"Resolve again" builds a new router from the current settings that shares the old one's health, so you can watch circuits open. With pinning on, it also passes the previous lock: versions stay fixed without a registry lookup, and only providers serving the same build can serve each package. Try it: resolve with jsDelivr first, then disable jsDelivr and resolve again.
