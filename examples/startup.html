mport examples / import maps at startup

Resolve once, then import natively

startup(router, specifiers) resolves each package, injects a <script type="importmap">, and returns the lockfile. After that, startup-app.mjs uses plain import { h, render } from "preact". The browser handles those imports itself, and mport is not involved.

How this page boots

import { createRouter, startup, esmSh, jsDelivr } from "mport";

const router = createRouter({ "*": [esmSh(), jsDelivr({ esm: true })] });
const { importMap, lock } = await startup(router, ["preact@^10", "preact@^10/hooks", "htm@^3"]);

await import("./startup-app.mjs"); // its static imports now go through the import map

Browsers only accept an import map injected after modules have started loading if they support dynamic import maps (Chromium 133+). Otherwise this page says so and loads the app through router.import() instead.
