mport examples

mport routes JavaScript imports across any number of CDNs. Which exact version you get is decided once; which CDN serves it can change. These pages run in your browser against the real CDNs. Serve the repo root (npm run demo:html) and open them from there.

Playground

Build a router, simulate CDN outages and latency, and watch each lookup on a timeline. Covers fallback, race, adaptive and prefer, integrity checks, the circuit breaker, and import-map and lockfile output.

Guided tour

Four short scenarios: the v1 race with debug info, a fallback past a dead mirror, routing by package name compiled to an import map, and retrying another CDN at runtime with router.import().

Import maps at startup

startup() resolves packages and injects a <script type="importmap">, then plain import "preact" works natively and renders a small app.
